# IscoT_PCD
O projeto pretende modelar um sistema de gestão doméstica através de domótica. Existirão sensores, decisores e atuadores que se ligarão a um servidor central, que fará a gestão de toda a comunicação no sistema distribuído. O componente central será um message broker1, aqui designado IscoT. O intuito é, com o apelo da atividade prática.
